# Traps: thirty-one things that failed quietly on the way to two shipped faces

WHAT IT'S FOR: the checklist the skill works through so a project does not pay for these again.
Each item names the symptom you would see, the cause, how it is detected, the guard that ships in
this repo, and where it bit: Bract (hopsafari.com, 2026-11-15, commit 90a085c) or Driftwood
(movingavg.com, 2026-11-14, commit 67a4e5b), with the numbers from their records. Read it at the
plan gate (phase 6) to check the plan covers each, and when a self-check or test goes red to find
the item it belongs to. The order is the plan's; items 1–29 are mechanisms, 30 is design, 31 is
the environment. Every script and flag named here was checked against the file it names
(`tests/test_docs_commands.py` keeps it that way).
